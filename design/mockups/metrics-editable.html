Note implementative
  • Peso: tap card -> entra in edit mode, mostra input numerico (formato italiano 78,2) + stepper +/- (step 0,1). Save su blur o invio. Slot vuoto = "— kg" tappabile per inserire.
  • Sonno: tap card -> mostra 2 input "7" e "12" (ore / minuti, due numeri). Save su blur.
  • Mood: tap card -> mood picker inline con 5 emoji (great/good/neutral/low/bad). Tap su un emoji = save immediato + chiude editor.
  • Dots: ingrandite (10 -> 14px) per essere tap-friendly. Tap toggla on/off, salvataggio immediato (no confirm). Persiste in `entry_goals` via upsert.
  • /mese: aggiorno DayRow per leggere i veri valori dall'entry invece dei deterministic-fake-via-hash. Se l'entry non ha metriche, mostro chip vuoti "—".
  • DB: schema 001_init.sql ha gia weight_kg / sleep_hours / sleep_label / mood + entry_goals table. Solo wiring lato app.
