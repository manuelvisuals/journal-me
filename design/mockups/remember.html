Note implementative
  • Schema: tabella `remembers` esiste gia (text, kind enum persona/libro/todo/nota/luogo/idea, source manual/extracted, source_entry_id FK).
  • Quick capture: input floating in basso (sopra tab bar). Tap su kind chip a destra apre dropdown per cambiare tipo. Tap "+" salva. Enter su input = salva.
  • Filtro: chip orizzontali scrollabili in alto. Tap chip filtra. Quando filtri per kind, il quick-capture default kind diventa quello (es. filtri "Persone" -> quick capture suggerisce kind=Persona).
  • Auto-extract: aggiungo step alla pipeline saveRecording / process-entry per chiedere all'AI di estrarre eventuali `remembers` dal transcript (es. "ricordati che X"). Tag source=extracted + source_entry_id. Per ora MVP: solo manuale, extract dopo.
  • Raggruppamento: vista "Tutti" raggruppa per giorno (Oggi / Ieri / Settimana scorsa / Mese scorso). Vista filtrata mostra tutti senza raggruppamento, ordinati per recency.
