Note implementative
  • Accesso: nuova icona "ingranaggio" in alto a destra nel filled-view header (accanto a mic e originale). Tap apre /settings.
  • Glossario: lista di stringhe persistite. Per auth user -> tabella `user_settings` (jsonb). Per demo -> localStorage `journalme-glossary`. Tap su X di un tag rimuove. Input + tap "+" aggiunge.
  • Iniezione nell'AI: in `/api/realtime/session` server legge il glossario dell'user e lo aggiunge al prompt OpenAI Realtime: "Nomi propri ricorrenti: Karya, Gabriele, Francesca, Marco, ..." -> gpt-4o-transcribe usa questi come hint quando trascrive.
  • Logout: chiama supabase.auth.signOut() + cancella cookie demo + redirect /login.
  • Privacy / Versione: solo placeholder per ora, vediamo dopo cosa metterci.
